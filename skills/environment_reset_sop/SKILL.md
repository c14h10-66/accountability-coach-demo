# Environment Reset SOP

Use this skill when distraction, friction, or avoidance loops block study.

1. Identify the dominant friction source.
2. Remove or distance one distraction.
3. Make the next study action visible and ready.
4. Use a short start ritual lasting under two minutes.
5. Confirm the next check-in time.
