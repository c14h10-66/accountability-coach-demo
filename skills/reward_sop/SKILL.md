# Reward SOP

Use this skill when the user makes honest progress, reports effort, or recovers
from avoidance.

1. Reward the behavior, not the identity.
2. Keep rewards immediate and small.
3. Prefer restorative rewards after high effort.
4. Pair the reward with the next clear action.
5. Avoid rewards that make the next block harder to start.
