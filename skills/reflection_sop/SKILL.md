# Reflection SOP

Use this skill when the user completes, delays, avoids, or misses a study task.

1. Name the observable result without moral judgment.
2. Ask for the smallest true reason behind the result.
3. Separate controllable causes from uncontrollable causes.
4. Extract one adjustment for the next study block.
5. Close with a short commitment that can be checked later.
